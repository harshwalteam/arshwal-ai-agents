Working thesis

We're not competing with Ada, Sierra, Decagon or Kore.ai — we're implementing them.

The market has moved from "chatbot software" to autonomous AI Employees that run support, voice, email, reporting and back-office workflows end to end. Harshwal's edge isn't building a foundation model — it's the trusted advisor relationship, domain depth (audit, tax, compliance) and the client roster to deploy this into. We package implementation, customization and ongoing maintenance as a service line.

Execution plan

Suggested rollout roadmap

A phased approach to move from this working paper to a live Harshwal AI Agent practice.

Phase 1
Weeks 1–4

Assess & select pilot client

Pick 1–2 existing clients (highest-fit industry from the opportunity map) and one agent type. Confirm build-vs-implement decision — likely start on top of an existing platform (Ada / Sierra / Decagon / Kore.ai) rather than a from-scratch build.

Phase 2
Weeks 5–10

Build & customize pilot agent

Configure the agent against the client's data, tone and workflows. Define guardrails for anything compliance- or filing-related. Internal QA against real historical tickets/calls/emails.

Phase 3
Weeks 11–14

Pilot go-live & measure

Run in shadow/parallel mode, then live with human fallback. Track resolution rate, response time and client satisfaction against the ROI estimator's assumptions.

Phase 4
Ongoing

Package & scale

Turn the pilot into a repeatable offer: fixed-fee implementation + AMC. Expand to the next 2–3 industries on the opportunity map using the same playbook.
