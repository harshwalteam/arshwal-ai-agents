Working thesis — AI Agents-as-a-Service (AaaS)

We're not competing with Ada, Sierra, Decagon or Kore.ai — we're implementing them, priced like a subscription.

The market has moved from "chatbot software" to autonomous AI Employees that run support, voice, email, reporting and back-office workflows end to end. Harshwal's edge isn't building a foundation model — it's the trusted advisor relationship, domain depth (audit, tax, compliance) and the client roster to deploy this into. We package this as AI Agents-as-a-Service: a small one-time onboarding fee, then a recurring per-agent subscription — just like a SaaS product, except the "software" is a working AI employee.

Position as an AI Agents-as-a-Service (AaaS) partner

Every agent is sold as a subscription seat, not a project: onboarding, customization, enterprise AI consulting, and ongoing tuning/support all bundled into one recurring price per agent, per client.

B

Sell through the existing relationship

Every current CPA, audit, and advisory client is a warm door for an AI Agent subscription — we already hold the trust and the data access.

C

Recurring, subscription-based revenue

A small one-time onboarding fee, then a monthly per-agent subscription that covers hosting, tuning, monitoring and support — predictable MRR instead of one-off project fees, and easy to bundle multiple agents into one invoice.

Execution plan

Suggested rollout roadmap

A phased approach to move from this working paper to a live Harshwal AI Agent practice.

Phase 1
Weeks 1–4

Assess & select pilot client

Pick 1–2 existing clients (highest-fit industry from the opportunity map) and one agent type. Confirm build-vs-implement decision — likely start on top of an existing platform (Ada / Sierra / Decagon / Kore.ai) rather than a from-scratch build.

Phase 2
Weeks 5–10

Build & customize pilot agent

Configure the agent against the client's data, tone and workflows. Define guardrails for anything compliance- or filing-related. Internal QA against real historical tickets/calls/emails.

Phase 3
Weeks 11–14

Pilot go-live & measure

Run in shadow/parallel mode, then live with human fallback. Track resolution rate, response time and client satisfaction against the ROI estimator's assumptions.

Phase 4
Ongoing

Package & scale

Turn the pilot into a repeatable AaaS offer: small onboarding fee + recurring per-agent subscription. Expand to the next 2–3 industries on the opportunity map using the same playbook.
